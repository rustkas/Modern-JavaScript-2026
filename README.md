# Modern JavaScript 2026

## Современный JavaScript в эпоху Web Platform, AI и Baseline
> От языка сценариев к архитектуре современной веб-платформы.

## 📖 О книге

За последние годы JavaScript проделал огромный путь.

Сегодня это не просто язык для анимации кнопок — это фундаментальная технология Web Platform, лежащая в основе современных веб-приложений, сложных пользовательских интерфейсов и даже приложений с искусственным интеллектом.

В книге рассматривается JavaScript 2026 года:

- новый синтаксис и возможности ECMAScript;
- работа с DOM и браузерными API;
- асинхронность и потоки данных;
- современные архитектурные подходы;
- интеграция с WebAssembly и AI;
- обзор актуальных фреймворков и их будущего.

Современные фреймворки:

- React
- Angular
- Vue
- Svelte
- Qwik
- Astro

не заменяют JavaScript.  
Они строятся **поверх JavaScript**, используя язык и веб-платформу как основу.

Эта книга показывает JavaScript как часть современной Web Platform.

## 🧠 Главная идея

Современный frontend строится на фундаменте Web Platform:

```
JavaScript
    |
    |-- логика и поведение

HTML
    |
    |-- структура и смысл

CSS
    |
    |-- внешний вид и layout
```

Фреймворки — это дополнительный уровень абстракции:

```
React / Angular / Vue / Svelte / Qwik / Astro
                    ↓
        JavaScript + HTML + CSS
                    ↓
        Browser Web Platform
```

В 2026 году JavaScript — это:

- **зрелый язык** с современным синтаксисом;
- **платформа** с сотнями встроенных API;
- **экосистема** с огромным количеством инструментов;
- **основа** для AI-приложений в браузере;
- **будущее** веб-разработки.
