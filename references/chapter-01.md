Список ключевых ссылок и ресурсов для **Главы 1. «Почему JavaScript снова изменился»**, составленный на основе материалов книги и актуальных данных 2026 года:

### Официальные стандарты и документация

- **Спецификация ECMAScript (Living Standard):** [https://tc39.es/ecma262/](https://tc39.es/ecma262/) — самый актуальный и точный документ, содержащий текст стандарта со всеми принятыми изменениями.
- **Архив ежегодных снимков (Snapshots):** [https://ecma-international.org/publications-and-standards/standards/ecma-262/](https://ecma-international.org/publications-and-standards/standards/ecma-262/) — история версий языка, включая официальное 17-е издание (ES2026).
- **Репозиторий предложений TC39:** [https://github.com/tc39/proposals](https://github.com/tc39/proposals) — площадка для отслеживания статуса новых функций от идеи (Stage 0) до включения в стандарт (Stage 4).

### Процесс развития языка

- **Документ о процессе TC39:** [https://tc39.es/process-document/](https://tc39.es/process-document/) — формальное описание пяти стадий (Stages), через которые проходит каждая новая фича JavaScript.
- **Завершенные предложения:** [https://github.com/tc39/proposals/blob/HEAD/finished-proposals.md](https://github.com/tc39/proposals/blob/HEAD/finished-proposals.md) — список всех функций, которые уже стали частью языка в последних версиях.

### Совместимость и Web Platform

- **Web Platform Baseline:** [https://web.dev/baseline/](https://web.dev/baseline/) — информация о новой модели совместимости, определяющей набор технологий, которые гарантированно поддерживаются всеми современными браузерами.
- **Can I Use:** [https://caniuse.com](https://caniuse.com) — сервис для проверки поддержки конкретных функций JavaScript и браузерных API в реальном времени.
- **MDN Compatibility Tables:** [https://developer.mozilla.org/](https://developer.mozilla.org/) — подробные таблицы совместимости с примечаниями по реализации для каждого браузера.

### Интероперабельность рантаймов

- **WinterTC (Technical Committee 55):** [https://wintertc.org](https://wintertc.org) — комитет, занимающийся стандартизацией общих API для серверных сред выполнения (Node.js, Deno, Bun) и облачных платформ.
- **Common Minimum API:** [https://github.com/wintercg/proposal-common-minimum-api](https://github.com/wintercg/proposal-common-minimum-api) — спецификация минимального набора API, который должен быть доступен в любой современной среде выполнения JavaScript.

### Ключевые новшества ES2026

- **Explicit Resource Management (`using`):** Описание синтаксиса для автоматического управления ресурсами.
- **Iterator Helpers:** Нативные методы для ленивых вычислений ( `.map()`, `.filter()` и др. для итераторов).
