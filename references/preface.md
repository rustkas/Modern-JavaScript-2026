### Список ссылок для Предисловия

*   **Официальная спецификация ECMAScript (Living Standard):** [https://tc39.es/ecma262/](https://tc39.es/ecma262/) — самый актуальный документ, содержащий последние завершенные предложения.
*   **Репозиторий предложений TC39:** [https://github.com/tc39/proposals](https://github.com/tc39/proposals) — статус всех новых фич от идеи до включения в стандарт.
*   **WinterTC (Technical Committee 55):** [https://ecma-international.org/technical-committees/tc55/](https://ecma-international.org/technical-committees/tc55/) — разработка общих API для серверных сред выполнения (Node.js, Deno, Bun).
*   **Web Platform Baseline:** [https://web.dev/baseline/](https://web.dev/baseline/) — информация о наборе технологий, которые гарантированно поддерживаются всеми современными браузерами.
*   **Таблицы совместимости:** [Can I Use](https://caniuse.com) и [MDN Compatibility Tables](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/118#http) — основные ресурсы для проверки поддержки фич в реальных условиях.
